# ADK Recipe Scaffolding

## Overview
Provides structured scaffolding for runnable Agent Development Kit (ADK) projects across core patterns and domain-specific community solutions.

## When to Use
- When initiating a new ADK agent project in Python, TypeScript, or Go.
- When exploring reference implementations for OAuth, multi-agent swarms, or RAG patterns.
- When validating recipe structure against the ADK recipe checklist and manifest standards.

## Core Capabilities
1. **Catalog Navigation**: Browses core and contrib recipe trees by vertical and complexity tier.
2. **Automated Setup**: Generates dependency lockfiles, environment variables, and execution runners.
3. **Manifest Validation**: Verifies `manifest.json` schemas and recipe placement rules.
